# Calculateur d'âge

Application mobile développée en .NET MAUI dans le cadre du TP1.

## Fonctionnalités

- Calcul de l'âge à partir d'une date de naissance
- Affichage du statut Majeur / Mineur
- Nombre de jours avant le prochain anniversaire
- Bouton Effacer pour réinitialiser les champs

## Architecture

Pattern MVVM avec navigation Shell entre deux pages.

## Lancer le projet

```bash
dotnet build -t:Run -f net10.0-windows10.0.19041.0
```
